# スプライトスタック試作（sprite-stack-proto）

ドット絵の断面（スライス）を積み上げて立体に見せる「スプライトスタック」を、three.js の3D空間で本物のボクセルとして積んだ試作フライトゲームです。
ブラウザで開けばそのまま遊べます。

**公開ページ**: https://oosawak.github.io/sprite-stack-proto/

## 遊び方

- ポインター（マウス／指）の左右で旋回、長押しでブースト
- タップ または T キー: 戦闘機 ⇔ ロボットの変形（スライスがバラけて組み直ります）
- R キー: バレルロール
- V キー: 視点切替（チェイス／真上）
- Z キー: 弾（長押しで連射）
- X キー: 爆弾投下
- N キー: 夜モード
- 画面のボタンでも同じ操作ができます

## 見どころ

- 機体は平面スライスではなくボクセル（箱）の積み重ね。斜めから見ても透けません
- 影は本物のシャドウマッピング。機体の形のまま影が落ちます
- 地形（島）も積み重ねで表現。草原・岩山・砂浜・森・雪山・火山のバリエーション
- 海には戦艦が周回しています。近づくと対空攻撃してきますが、たまに潜ります。弾と爆弾で撃沈もできます
- 翼端からたまに白い飛行機雲が出ます。雲に当たり判定はありません
- 左下にレーダーがあります（機首方向が上。島は緑、戦艦は赤、潜水中は青丸）

## 敵機

v0.11 から、敵として暗色ステルス仕様の変形戦闘機（これも Gemini 生成の .vox 由来）が 3 機登場します。
前進翼の戦闘機、両腕ブラスターの中間形態、角のあるロボットの 3 形態に変形しながら、プレイヤーを追尾して撃ってきます。
こちらの弾は 1 発 1 ダメージ（HP 6）、爆弾は 3 ダメージです。倒すと爆発して、しばらくすると別の場所に再出現します。
レーダーでは紫の点で表示されます。

## 変形の仕組み

v0.10 から、機体は Gemini が生成したボクセルモデル（MagicaVoxel .vox 由来の 3D グリッド）になりました。
変形ボタンで 戦闘機 → 中間形態 → ロボット → 戦闘機 と循環します。
形態ごとに速度が変わります（中間形態 0.78 倍、ロボット 0.55 倍）。
弾の発射位置も形態ごとに違います（戦闘機は翼の砲、中間形態は中央のガンポッド、ロボットは両腕）。

v0.12 から、自機（白）の変形は Gemini 製ゲーム「Voxel Valkyrie」と同じ方式になりました。
2つの形態のボクセルを番号順に対応付け、ボクセルが直線で飛んで組み替わります（個数が違う分は小さく生えて／縮んで消えます）。
敵機（黒）の変形は、従来どおり放射状にほどけて組み替わる方式のままです。

v0.13 からロボット形態で、v0.14 から中間形態でも止まれるようになりました。
形態ごとに動きの性格が違います。

- 戦闘機: 最速。止まれず、まっすぐ飛び続けます。旋回はゆるやかです
- 中間形態: 止まれます。旋回が一番速く、止まったままその場で回転（ピボット旋回）できます。長押しで移動します
- ロボット: 止まれます。旋回は中くらい。止まったまま向きを変えて撃てるので、戦艦や敵機への狙撃に向きます。長押しで移動します

v0.9 までの「戦闘機と同じボクセル（2,436 個）を組み替えてロボットにする」方式は、index-v0.9.html に残っています。

## 技術メモ

- three.js は同梱しています（`three.module.js`、CDN 不使用）
- 機体のボクセルは、ドット絵と「高さクラス」の定義から実行時に生成しています
- 描画は内部解像度を落として拡大し、ドット感を保っています
