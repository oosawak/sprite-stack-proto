# スプライトスタック試作（sprite-stack-proto）

ドット絵の断面（スライス）を積み上げて立体に見せる「スプライトスタック」を、three.js の3D空間で本物のボクセルとして積んだ試作フライトゲームです。
ブラウザで開けばそのまま遊べます。

**公開ページ**: https://oosawak.github.io/sprite-stack-proto/

## 遊び方

- ポインター（マウス／指）の左右で旋回、長押しでブースト
- タップ または T キー: 戦闘機 ⇔ ロボットの変形（スライスがバラけて組み直ります）
- R キー: バレルロール
- V キー: 視点切替（チェイス／真上）
- Z キー: 弾（長押しで連射）
- X キー: 爆弾投下
- N キー: 夜モード
- 画面のボタンでも同じ操作ができます

## 見どころ

- 機体は平面スライスではなくボクセル（箱）の積み重ね。斜めから見ても透けません
- 影は本物のシャドウマッピング。機体の形のまま影が落ちます
- 地形（島）も積み重ねで表現。草原・岩山・砂浜・森・雪山・火山のバリエーション
- 海には戦艦が周回しています。近づくと対空攻撃してきますが、たまに潜ります。弾と爆弾で撃沈もできます
- 翼端からたまに白い飛行機雲が出ます。雲に当たり判定はありません
- 左下にレーダーがあります（機首方向が上。島は緑、戦艦は赤、潜水中は青丸）

## 変形の仕組み

v0.10 から、機体は Gemini が生成したボクセルモデル（MagicaVoxel .vox 由来の 3D グリッド）になりました。
変形ボタンで 戦闘機 → ガウォーク → ロボット → 戦闘機 と循環します。
形態ごとに速度が変わります（ガウォーク 0.78 倍、ロボット 0.55 倍）。
弾の発射位置も形態ごとに違います（戦闘機は翼の砲、ガウォークは中央のガンポッド、ロボットは両腕）。

v0.9 までの「戦闘機と同じボクセル（2,436 個）を組み替えてロボットにする」方式は、index-v0.9.html に残っています。

## 技術メモ

- three.js は同梱しています（`three.module.js`、CDN 不使用）
- 機体のボクセルは、ドット絵と「高さクラス」の定義から実行時に生成しています
- 描画は内部解像度を落として拡大し、ドット感を保っています
