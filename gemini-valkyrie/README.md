# Gemini 生成ボクセルモデル（自機・敵）

Gemini が生成した Python スクリプトと、その出力（MagicaVoxel .vox、スプライトスタックのシート画像、プレビュー）です。
ゲーム本体（../index.html）は、この .vox のグリッドデータを変換して埋め込んでいます。

- valkyrie.py — 自機の変形戦闘機3形態（戦闘機／中間形態／ロボット）の生成器
- enemy_valkyrie.py — 敵の変形戦闘機（暗色ステルス仕様）3形態の生成器。前進翼・角・モノアイ
- *.vox — MagicaVoxel 形式のモデルデータ
- sheet_*.png — 各形態のスプライトスタックシート（Zスライスを横に並べたもの）
- *_preview.png — アイソメトリックのプレビュー画像
